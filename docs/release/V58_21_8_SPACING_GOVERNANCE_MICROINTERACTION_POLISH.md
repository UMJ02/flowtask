# v58.21.8 — Spacing Governance + Microinteraction Polish

Base: v58.21.7 Style Cascade Reset + Interaction Polish
Stage: production-candidate

## Summary

v58.21.8 continues the visual cleanup by reducing excess air between cards, tightening the global rhythm, and adding more deliberate microinteraction classes. It does not modify Supabase, RLS, migrations, data payloads or product logic.

## Included

- More compact global spacing scale.
- Smaller default page/card rhythm.
- Tighter card, toolbar, table and action spacing.
- Flatter surfaces by default.
- Raised/floating/overlay surfaces remain named variants.
- New motion utilities for pop, expand, slide-fade and arrow actions.
- Public/auth oversized typography and heavy shadows reduced.
- Legacy oversized spacing patterns removed from source.
- New living system document for spacing and microinteractions.

## Not included

- No Supabase migrations.
- No RLS changes.
- No new product features.
- No structure changes to task/project workflows.
