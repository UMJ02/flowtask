# v58.28.9 — Workspace Pro Brand Pastel Loading System

Base: v58.28.8.

## Objetivo
Ajustar la identidad visual de Workspace Pro con verdes de marca y pasteles tipo versión básica, manteniendo la sidebar interna blanca.

## Cambios
- Cintillo de cambio de vista full-width, sobrio y en verde FlowTask/pastel.
- Reemplaza el gradiente rojo/azul/ámbar por tonos mint, emerald y verde de marca.
- Home y cards reciben acentos pastel más suaves.
- Tabs y botones activos bajan contraste agresivo y usan verde de marca.
- No cambia lógica, Supabase, RLS ni migraciones.

## Validación
- `npm run verify:current`
- `npm run workspace:brand-pastel:ready`
- `npm run build:preflight`
