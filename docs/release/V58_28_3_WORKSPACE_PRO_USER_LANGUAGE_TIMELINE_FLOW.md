# v58.28.3 — Workspace Pro User Language + Timeline Flow

Versión enfocada en remover textos técnicos visibles, limpiar el board, alinear la edición rápida de tareas y convertir Timeline en una vista operativa más útil.

## Cambios
- Se eliminan textos robotizados del Board.
- El menú de acciones de la card queda por encima de otras tarjetas.
- La edición rápida de tareas coloca estado, prioridad, fecha y accesos en una misma línea responsive.
- El editor rápido del Board elimina duplicados y queda más compacto.
- Espacios deja de mostrar migraciones/nombres técnicos en la UI.
- Timeline muestra filas accionables con fecha, tipo, contexto, avance, estado y prioridad.

## Sin cambios
No toca Supabase schema, RLS, migraciones, rutas clásicas ni dependencias.
