# v58.27.2.1 — Workspace Pro Layout Simplification + Interaction Cleanup

This release refines the v58.27.2 visual reset into a cleaner, more professional workspace layout.

## Focus

- Sidebar only handles navigation: principal, spaces, projects, system.
- Workspace views live only in the top tabs, avoiding duplicate navigation.
- Header is compact and keeps a single primary CTA: Nueva tarea.
- Secondary actions are grouped under the more menu or sheets.
- Quick create, saved views, and spaces manager now open as overlay sheets instead of pushing the whole page down.
- Right panel is now an optional inspector and starts closed by default.
- Home uses compact metric chips instead of large dashboard cards.
- List rows no longer render the inline editor permanently; editing appears only after selecting the row action.
- Board cards no longer show always-visible quick move controls.

## No changes

- No Supabase changes.
- No migrations.
- No RLS changes.
- No route replacements.
- No new dependencies.
