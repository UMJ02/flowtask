# FlowTask v58.27.4 — Workspace Pro Board Drag Drop + Inline Editing

Esta versión fortalece la vista Board del Workspace Pro para que sea una superficie real de operación: drag/drop entre columnas, columnas visibles configurables, edición contextual de tareas y acceso a edición completa.

## Alcance

- Board con columnas de producción reales.
- Concluido oculto por defecto.
- Mostrar concluidas opcional.
- Columnas visibles configurables.
- Drop zone visual al arrastrar tareas.
- Edición contextual en sheet: nombre, estado, prioridad, fecha y proyecto.
- Acceso a detalle y edición completa.
- Sin migraciones nuevas.
- Sin cambios RLS.
