# v58.25.3 — Settings Width + Compact Hero/Metrics

**Base:** v58.25.2 — Settings Colorful Redesign Alignment

## Problema

La vista de Settings quedaba más angosta que el header, dejando espacios laterales innecesarios. Además, el hero y las metric cards estaban demasiado grandes.

## Solución

- Settings shell pasa a ocupar todo el ancho del contenedor disponible.
- Hero más bajo y compacto.
- Ilustración del hero reducida.
- Métricas reducidas en alto, padding e iconografía.
- Se preserva el rediseño colorido y la funcionalidad actual.
