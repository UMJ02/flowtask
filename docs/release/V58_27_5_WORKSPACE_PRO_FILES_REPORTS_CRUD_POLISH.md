# v58.27.5 — Workspace Pro Files + Reports CRUD Polish

Esta versión pule las vistas Archivos y Reportes dentro de Workspace Pro.

## Incluye
- Upload entry integrado en Archivos.
- Lista de archivos con abrir, descargar, renombrar y eliminar.
- Tabla visual de archivos con tipo, tamaño y contexto.
- Pizarras relacionadas más accionables.
- Reportes configurables por rango y proyecto.
- Acciones para abrir reportes, vista imprimible y exportador.

## No incluye
- Nuevas migraciones.
- Cambios de RLS.
- Nuevas dependencias.
- Reemplazo de rutas clásicas.
