# v58.27.3 — Workspace Pro Interaction Model + Task/Project UX

Esta versión convierte el Workspace Pro en una experiencia más accionable y menos pasiva.

## Cambios

- Lista cambia su propósito a vista de Tareas operativas.
- Nueva vista Proyectos para separar proyectos y tareas anidadas.
- Home ahora enlaza tareas, proyectos, recursos y actividad.
- Quick Create ahora permite elegir Tarea o Proyecto.
- Quick Create corrige overflow y elimina scrollbar horizontal.
- Tareas pueden tener checklist opcional al crearse.
- Proyectos pueden crearse con tareas iniciales.
- Board agrega columnas Pendiente, En curso, Producción, En espera y Revisión.
- Concluido queda oculto por defecto con opción Mostrar concluidas.
- Board permite elegir columnas visibles.
- Board permite drag/drop entre columnas y actualiza status.
- Cards del board permiten edición rápida y abrir detalle completo.
- Timeline muestra tareas/proyectos con fecha, estado y avance.
- Home agrega dock derecho simple: fecha, nota rápida, acciones rápidas.

## Sin cambios de riesgo

- No cambia RLS.
- No toca safe_delete_visual_board.
- No reemplaza rutas clásicas.
- No instala dependencias.
