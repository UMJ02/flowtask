# QA — FlowTask v58.27.2 Workspace Pro Design Reset

## Checklist visual

- `/app/workspace` debe verse más limpio y menos cargado.
- Sidebar sin cards, permisos o métricas grandes.
- Header compacto con proyecto, breadcrumbs, CTA y compartir.
- Tabs de views pequeñas y en una línea cuando sea posible.
- Home sin repetición de permisos, health, migration guard o bloques técnicos.
- Right panel opcional y compacto.
- No debe haber scrollbars internas visibles innecesarias salvo scroll principal.

## Checklist funcional

- Abrir Home.
- Cambiar a Lista, Board, Timeline, Tabla, Canvas, Archivos y Reportes.
- Crear tarea desde CTA.
- Editar estado/prioridad inline en Lista.
- Abrir Command Center.
- Abrir Share Panel.
- Abrir Spaces Manager.
- Abrir Saved Views Manager.
- Confirmar que las rutas clásicas siguen vivas.

## Criterio de aceptación

La pantalla debe sentirse más cercana a una herramienta SaaS profesional: menos ruido, acciones claras, menos repetición y navegación más simple.
