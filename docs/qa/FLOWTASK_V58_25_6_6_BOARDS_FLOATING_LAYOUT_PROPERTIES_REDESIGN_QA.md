## CLI

```bash
npm install

npm run design:doctor
npm run typecheck
npm run build:preflight
npm run build
npm run dev
```

## Manual

1. Abrir una pizarra.
2. Seleccionar una tabla.
3. Verificar que la toolbar superior no quede debajo del panel.
4. Verificar que el minimap quede visible y pueda ocultarse/mostrarse.
5. Contraer el panel y validar el rail de iconos.
6. Expandir el panel.
7. Editar X/Y/W/H.
8. En tablas, cambiar filas/columnas y renombrar columnas.
