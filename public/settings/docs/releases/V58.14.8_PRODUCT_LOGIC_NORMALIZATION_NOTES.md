# FlowTask V58.14.8 Product Logic Normalization PASS

Base: V58.14.7 Final Interactive Connections PASS.

## Objetivo
Normalizar la lógica operativa de estados en toda la app para evitar falsos vencidos y separar trabajo activo de historial concluido.

## Reglas aplicadas
- `en_proceso`: cuenta como trabajo activo y puede vencer si `due_date < hoy`.
- `en_espera`: no cuenta como vencida; se trata como standby y muestra días en espera en vistas de tarea.
- `concluido`: se oculta por defecto de vistas operativas y no cuenta como vencida.
- Las concluidas se pueden consultar desde el anexo/filtro `Ver concluidas / reactivar`.
