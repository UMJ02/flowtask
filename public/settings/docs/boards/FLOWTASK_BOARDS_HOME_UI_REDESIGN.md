# FlowTask Boards Home UI Redesign

La pantalla `/app/boards` queda organizada en:

- Hero superior con copy claro y preview visual.
- Plantillas rápidas con tarjetas pastel.
- Pizarras recientes con mini previews.
- Acción de crear nueva pizarra.
- Acción de eliminar pizarras guardadas con confirmación.

El diseño sigue los tokens:

- Background: `#F6F8FB`
- Cards: `#FFFFFF`
- Bordes: `#E8EDF5`
- Verde: `#22C55E`
- Pasteles: azul, morado, amarillo y rosado suaves.
