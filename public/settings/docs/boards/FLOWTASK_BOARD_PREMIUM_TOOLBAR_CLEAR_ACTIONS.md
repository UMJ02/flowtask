# FlowTask Boards — Premium Toolbar + Clear Actions

La paleta del editor ahora actúa como una herramienta flotante profesional: se puede mover, expandir, contraer y ocultar.

La acción Limpiar pizarra no elimina la pizarra: solo marca como borrados todos los elementos del lienzo con soft delete y registra actividad.

La configuración visual se guarda en localStorage para evitar nuevas tablas o migraciones.
