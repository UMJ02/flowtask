# QA — v58.23.1 Board Connectors + Properties Panel

## CLI

```bash
npm run verify:v58.23.1
npm run typecheck
npm run build:preflight
npm run build
npm run dev
```

## QA visual

1. Abrir `/app/boards`.
2. Crear o abrir una pizarra.
3. Insertar dos formas o notas.
4. Seleccionar la herramienta **Conector**.
5. Click en el primer elemento.
6. Click en el segundo elemento.
7. Confirmar que aparece línea con flecha.
8. Seleccionar el conector.
9. Editar color, grosor, tipo y etiqueta en el panel derecho.
10. Recargar y confirmar que el conector persiste.
11. Mover un elemento conectado y confirmar que el conector se ajusta.
12. Borrar el conector con toolbar o Delete.
13. Confirmar autosave y recarga.
