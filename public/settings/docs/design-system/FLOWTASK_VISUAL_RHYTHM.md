# FlowTask Visual Rhythm System

Base: v58.21.6.

## Principio

FlowTask usa una interfaz compacta, ligera y orientada al contenido. El objetivo no es decorar la app, sino facilitar lectura, acción y seguimiento.

## Reglas

- No usar sombras decorativas en cards normales.
- Usar bordes suaves y fondo blanco como separación principal.
- Reservar sombras para modales, drawers, menús flotantes y overlays.
- Evitar cards dentro de cards si una lista o panel simple resuelve mejor.
- Los títulos internos no deben competir con el título de página.
- Inputs grandes solo en casos de composición editorial; no en formularios operativos.
- Las animaciones deben ser sutiles: reveal, slide-fade y active scale.

## Escala

- Page title: 24-28px.
- Section title: 17-19px.
- Card title: 14-15px.
- Body: 14px.
- Meta: 11-12px.
- Buttons: h-9 normal, h-10 CTA principal.
- Inputs: h-9 normal, h-10 destacado.
- Cards: p-4 main, p-3.5 section, p-3 compact.
